# WeatherData_111

Companion repository for the *Research Topics 111* course (M2 Économie Internationale et
Développement, Université Paris-Dauphine): a short R pipeline that downloads ERA5
weather data for Europe, checks it, aggregates it in time and space, merges it with Eurostat
regional GDP, and runs a first income-temperature regression.

Kept deliberately simple: one month of data at coarse resolution, so the whole pipeline runs in
minutes and is easy to read end to end. See `presentation/WeatherPipeline.qmd` for what that
means in practice and how to extend it into a real research design.

## What's in this repository

| Path | What it is |
|---|---|
| `scripts/` | **The pipeline.** 8 short R scripts, `running_all.R` sources them in order. Start here. |
| `Presentation/WeatherPipeline.qmd` | Presentation slides walking through the pipeline step by step: data formats, folder layout, and what each script does. |
| `code/ERA5_APIKey.R` | Your personal Copernicus Climate Data Store (CDS) access token to be able to download from CDS API. **Not included** (gitignored). |
| `data/source/` | Raw downloads (ERA5 NetCDF files). The pipeline will feed this folder with data. |
| `data/intermediary/`, `data/final/` | Derived data the pipeline produces (cell-level and NUTS3-level aggregates, the merged panel).  |
| `figures/`, `tables/` | Every check map, time series, and the regression output the pipeline writes.  |

Data files are intentionally not tracked in this repository (see `.gitignore`): ERA5 downloads,
derived rasters, and the merged panel are all regenerated by running the pipeline, and keeping
them out of git keeps clones small. 

## Quick start

0. Have **R** and **RStudio** installed (no need for Git - you can just download this repository
   as a ZIP from GitHub).
1. Download or clone this repository, then open `era5-weather-data-economics.Rproj` in RStudio.
2. Get a CDS personal access token: register at <https://cds.climate.copernicus.eu>, then copy
   your key from <https://cds.climate.copernicus.eu/how-to-api>. Save it as
   `code/ERA5_APIKey.R` containing one line: `key_loic <- "your-key-here"` (this file is
   gitignored - never commit it).
3. Open `scripts/00_preamble.R` and set `cfg$month` to your own birth month if you'd like a
   personalized run.
4. Run `scripts/running_all.R`. It downloads, checks, aggregates, merges, and regresses, writing
   everything to `data/`, `figures/`, and `tables/`.
5. Open `Presentation/WeatherPipeline.qmd` (or render it with `quarto render`) to follow along
   with what each step just did.
